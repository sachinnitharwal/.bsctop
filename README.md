🌐 BSC TOP — Educational Resource Platform

🚀 Overview

BSC TOP is a student-centric educational web platform designed to streamline access to academic resources for BSc students. The platform centralizes study materials, assignments, previous year papers, and curated learning content into a single, easy-to-navigate interface.

This project demonstrates strong fundamentals in frontend development, UI structuring, and content organization, making it suitable for real-world academic use.

---

✨ Key Features

- 📚 Centralized study materials & notes
- 📝 Access to assignments and previous year papers (PYP)
- 📖 Buy & Sell Books functionality
- 🎥 Curated lectures and playlists
- 📰 Integrated blog system
- 🔐 Basic authentication interface (login/admin panel)
- 📢 Notice board for updates
- 📱 Fully responsive design

---

🧠 Problem Statement

Students often struggle to find reliable academic resources scattered across multiple platforms.
BSC TOP solves this by providing a unified, structured, and accessible learning hub.

---
